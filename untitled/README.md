# HAI-X1: tecnología emergente

## Bienvenida

HAI-X1 propone colaboración entre inteligencia humana y artificial.

El objetivo no es reemplazar a las personas. El sistema contrasta aportes y aprende con ellas. Su resultado debe evaluarse mediante capacidades cooperativas medibles.

{% hint style="info" %}
HAI-X1 está en fase de prototipo conceptual. Las ideas visuales y de bienestar requieren validación experimental independiente.
{% endhint %}

* **Para quién es:** personas que diseñan, investigan o evalúan sistemas de IA.
* **Aprenderás:** a definir, prototipar y medir interacciones humano-IA cooperativas.
* **Crearás:** un diseño experimental inicial para validar una capacidad cooperativa.
* **Requisitos:** nociones básicas de IA, investigación de usuarios y evaluación.
* **Duración:** menos de una hora.

### Objetivos del curso

1. Definir el principio fundador de HAI-X1.
2. Distinguir colaboración de sustitución humana.
3. Diseñar una interacción de contraste y aprendizaje mutuo.
4. Elegir métricas observables para la cooperación.
5. Plantear una validación experimental responsable.

### 1. Parte del principio fundador

Diseña una arquitectura donde cada participante aporte capacidades distintas.

La persona aporta contexto, criterio y responsabilidad. La IA aporta procesamiento, alternativas y trazabilidad. Ambos revisan sus resultados antes de actuar.

### 2. Diseña el ciclo cooperativo

Usa un ciclo claro:

1. La persona plantea un objetivo y sus límites.
2. La IA propone opciones con sus supuestos explícitos.
3. La persona contrasta, corrige o descarta las opciones.
4. El equipo registra el resultado y evalúa la interacción.

Evita atribuir conciencia, intención o certeza a la IA. Describe siempre sus límites y fuentes de error.

### 3. Mide capacidades cooperativas

Define métricas antes de experimentar. Elige medidas que reflejen el objetivo humano.

* **Calidad de decisión:** precisión, consistencia o cobertura del resultado.
* **Control humano:** cambios aceptados, rechazos y anulaciones.
* **Eficiencia verificable:** tiempo, iteraciones y correcciones necesarias.

Compara el resultado cooperativo con una línea base. Puede ser trabajo humano individual o un flujo automatizado.

### 4. Valida de forma responsable

Formula una hipótesis concreta. Por ejemplo: “El ciclo de contraste reduce las correcciones necesarias”.

Prueba el flujo con tareas acotadas y criterios de éxito definidos. Documenta sesgos, fallos y casos no resueltos. No presentes hipótesis como resultados comprobados.

{% hint style="warning" %}
No uses este marco para prometer curación, manifestación o cambios garantizados. Las afirmaciones sobre salud requieren evidencia clínica adecuada.
{% endhint %}

### Resultado esperado

Al terminar, tendrás una propuesta de interacción humano-IA, una métrica prioritaria y un experimento inicial. HAI-X1 puede avanzar desde el prototipo conceptual mediante validación reproducible.
